每批先登记具体目标和知识候选，再外搜并保存原件，核实后补入 `data/china-card-reading.js` 与图片配置。新内容由中国统一卡片库整合，列表只显示简短摘要，300–500字在既有详情页阅读；不新建重复网页，也不改变欧洲内容。

原始风物记录、旧阅读笔记及历史验收收据继续保留。补充后的旧摘要和简记在运行时保留为 `originalDescription`、`originalReading`，详情不再同时展示过时的“做法待补充”。当前阅读内容、原始记录与来源可以各自追溯。

后续可按队列选取：先处理短说明与缺图兼有的条目，兼顾省市分布；优先读取非遗项目、地方政府、博物馆、地方志、生产者和可信媒体。图片需另查对应主题、作者、许可、清晰度与构图。无图或质量不足就待补，不以门店外景、摊位杂照、其他地域版本、通用图或生成图凑覆盖率。

维护入口：`node scripts/china-enrichment/refresh-queue.cjs` 更新全量队列，`python scripts/index-china-research.py` 更新总索引。每轮内容以实际采用记录为准；本目录不代表后台自动收集或无人审阅发布。
