# 超过4000项：逐省市县三步研究

范围沿用当前食单15省市，登记15个省级、174个市级和1484个县级单元，共1673个层级单元。北京、上海的省级与市级即使行政代码相同也分开记账，产品不重复计数。

## 底稿与阶段

| 文件 | 用途 |
| --- | --- |
| [knowledge-draft.txt](knowledge-draft.txt) | 本轮外搜前写下的自身知识原稿 |
| [knowledge-candidates.json](knowledge-candidates.json) | 2046条候选记录、初步分类及记忆归属；重复名称和别名仍需核对 |
| [external-searches.json](external-searches.json) | 逐地组合查询、共享结果链接、完整响应指纹；不等于已读来源 |
| [progress.json](progress.json) | 每个层级单元的知识、外搜、交叉审阅进度与剩余缺口 |

| `readings/` | 本轮802个来源的事实笔记、实际读取方式和原件指纹 |

当前目录4255项（4208项有来源、47项待核实）；本轮新增2143项，另作363次别名合并或来源补充。自身知识候选2046条，3346次查询覆盖1673个当前行政单元；原知识稿768条仍待更多证据、18条暂缓或否决。1500项说明达到300–500字，2755项待补，不将目录数量达标当作研究和扩写全部完成。

先查看完整行政名单并保存知识候选，再执行本轮外部检索。没有回忆到具体名称的单元记录为知识缺口，不据此断言当地没有美食。模型上下文包含此前研究内容，本轮记忆稿不视为独立盲测或来源证据。不得用外搜后才看到的内容回填初始记忆稿，伪造独立互证。

每个单元执行两组组合关键词查询：一组针对特色菜、面食、地方小吃和小众美食，另一组针对乳品、饮品、酒、茶、食材、调味品和特产。组合查询不是各品类的穷尽研究；同批最多两个地区、四个查询共享结果链接，链接不自动证明任何单条食品归属。

完整查询响应在 `research/.local/program-4000/geo-search/`，原始公告、读取的正文和处理记录在该本地目录的其他子目录。公开底稿保留采用的事实、指纹和审阅结论，不镜像第三方全文。GitHub项目若使用模型提取、推断或补写，只作线索；公告原文的名称、范围与品质段需另行核对。

交叉审阅应保留：初始候选ID、外部记录、实际已读来源、地域或类别纠正、别名合并到的既有ID、采用或待核理由。原文支持范围和缺口必须明示，不能把“有来源”“名称吻合”和“全部事实验证”混为一谈。

读取534份公告镜像PDF，2025年第640、646号另外读取原站PDF并核对完整提取文本；其余镜像保留固定提交，不声称原站字节已验证。GitHub项目的模型提取与润色文本不作独立事实依据。记忆候选尝试747个正文链接，549个可读取、198个失败或不足；实际采用的正文记录名称与地域核对范围，不自动证明配方。程序提取、段落定位和正文匹配的读取方式均随来源记录，不声称所有长文均逐页人工阅读。

维护工具在 `scripts/flavor-program/`：`adopt.py` 为已审阅批次的单次导入，拒绝重复应用；`review-details.py` 重核产品边界与说明；`reconcile.py` 更新交叉审阅和进度。后两者依赖保留的本地输入，不改初始知识稿。查询索引用 `scripts/index-flavor-program-searches.py` 刷新。原始下载、完整响应及一次性检索脚本保留在本地研究目录，公开只保存事实、索引及指纹。

## 网页说明

目标至少4001项，数量不靠别名、包装规格、同一企业不同口味或无依据的县域复制增加。每项说明以300–500字为目标，放在现有卡片的原生展开区域；用具体信息扩写，不新增独立说明页面。资料不足时继续补证，不凭空补写历史与风味。

字数统计采用正文Unicode字符数（含标点），不含摘要、来源与备注。地理标志公告中的原料、感官和生产条件描述的是规范要求，不等于所有商家或实际批次均符合。未明确食品用途的药材和观赏品暂缓，明确的地方工艺品另归物品与工艺。
