# 漫游词典 · Eurotrip

面向匈牙利、奥地利和德国旅行的中文网站：国家与城市知识、关联卡片、分层地图，以及中文 → 英语 → 匈牙利语 → 德语的旅行词典。

公开网址：https://cafelzj.github.io/eurotrip/

## 本地运行

纯静态 HTML、CSS、JavaScript，无需安装应用依赖：

```sh
cd /workspace/eurotrip
python3 -m http.server 3014 --bind 0.0.0.0
```

浏览器访问站点即可使用。地图底图、即时门店查询、官方资料及词典外链需要联网；设备朗读取决于系统语言包。收藏与地图偏好保存在当前浏览器。

## 页面与卡片约定

顶部「国家知识」菜单选择国家，页面内统一选择国家概览或城市。目前覆盖三国、十座城市。国家与城市使用相同的目的地标题、选择器、基本信息和卡片布局。

五个**卡片一级分类**：🧭 必备信息、🍽️ 美食与特产、🛍️ 购物、💡 冷知识与人物、🏛️ 景点与建筑。每类下按**卡片二级分类**分组，例如交通买票、机场、咖啡、超市、剧院。博物馆、美术馆与展览馆统一归入「博物馆 / 美术馆 / 展览」；「公园 / 游乐园」收录大森林公园、英国花园及普拉特游乐园，温泉与山地起点另归「其他景点」。「连锁餐饮」同时展示连锁品牌和具体门店，地图行为仍分别为动态搜索与单点定位；「美食」与「甜品」分开展示。一级分类有简介，二级分类有专门总结；分类只有筛选与展开，不设置详情页。

二级分类独立展开，每组先显示三张，可继续加载。支持关键词、一级分类和二级分类组合筛选，URL 保留筛选状态。城市只展示明确关联的内容，并保留标明适用范围的全国/通用必备提醒。

仅保留可在国家知识集合中找到的独立卡片详情，目前初始共 363 张。国家、城市与地图使用各自的指南/地图路由，不再创建重复卡片；词汇继续使用现有四语详情对话框。卡片之间保留有明确意义的双向知识关联和官方来源，但知识关联不推导地图坐标。旧的卡片漫游与分类详情渲染代码已删除。

每张卡片只有以下一种地图行为，由 `KnowledgeHub.mapBinding` 集中判定：

| 行为 | 数据与交互 |
| --- | --- |
| 无地点 | 没有地图定位按钮；相关人物、菜肴、趣闻不会继承关联场所的坐标 |
| 一个固定 POI | 卡片自身的一个 `point`；卡片编号与唯一大头针对应，可双向定位 |
| 动态搜索 | 无固定坐标的超市品牌、连锁餐饮品牌或购买线索；进入地图后按范围搜索 |

连锁品牌用于搜索；搜索结果先登记为具体门店卡片，每张结果卡片只有一个固定位置。品牌与多家门店之间是知识关联，不代表品牌卡片关联多个固定 POI。餐馆、博物馆、教堂、剧院、大学、机场、车站、轮渡码头等具体场所均采用单个参考位置。

常用路径：

- `#guide/at`：国家概览。
- `#guide/at/vienna?zone=food`：维也纳的美食与特产。
- `#card/person-mozart`：人物详情，可继续访问关联的纪念馆卡片。
- `#map/at`：国家卡片地图。
- `#map/vienna`：城市卡片地图。
- `#map/vienna?focus=venue-vienna-opera`：定位一张具体地点卡片。
- `#map/vienna?search=brand-chain-nordsee`：在当前城区动态搜索该连锁。
- `#map/hu?search=food-product-turo-rudi`：选择采购线索后放大到要探索的城区，查询超市；不保证库存。
- `#words`：旅行词典；`#cards` 兼容跳转至最近浏览国家。

## 地图与动态门店

右下角「随身地图」默认收起，展开时初始化，收起时销毁；桌面默认宽 460px、画布高 340px，可继续放大。五个一级分类分别作为图层。每个固定 POI 使用对应卡片的名称、编号、图标、简介和详情链接，不沿关联卡片展开多个点；无地点的详情不会显示虚构大头针。国家和城市模式都提供「打开地图页面」入口。词典与完整地图页隐藏随身地图。

完整地图共用国家/城市渲染器，内容与分类只来自当前目的地卡片。图层面板改为「一级分类 → 二级分类 → 卡片」的三层树。箭头独立展开/收起，复选框控制显示；父级按子卡片计算全选、取消和半选，不再叠加三套过滤状态。卡片叶子显示名称、编号及详情入口，点击地点定位并高亮树中对应项；动态品牌叶子注明「动态搜索」，勾选后按范围查询，点击名称可直接选择该品牌搜索。桌面左侧树形面板、右侧地图，手机上下排列。动态结果不追加到树中，继续在地图聚合与结果列表展示，品牌叶子提示已载入数量。共享品牌在详情和地图跳转时保留当前国家/城市语境，不把经营市场当成品牌起源或总部。

默认不请求外部门店。开启动态搜索后，移动地图经 900ms 防抖查询；可关闭自动搜索，也可手动查询或取消。浏览器直接 POST 到 `https://overpass-api.de/api/interpreter`，不需要密钥，只查询已收录品牌，响应再次检查品牌身份。

- 缩放至少 13，视野宽、高各不超过 15km；国家地图需先放大到城区。
- 每次最多保留 200 个门店，列表最多显示离中心最近的 30 个；地图使用 MarkerCluster 聚合。
- 品牌/name/operator 合并匹配；相同在途请求去重。范围按 0.005 度外扩对齐，缓存 10 分钟，内存最多 24 项、当前会话最多保存 8 项。
- 服务端计算超时 8 秒，客户端最多等待 10 秒，显示耗时并可取消。失败后自动搜索冷却 15 秒，手动重试仍可用；已有结果保留。
- 地点卡片的独立显示偏好按国家/城市保存，并兼容迁移原有分类开关；动态品牌每次进入默认关闭，明确的搜索深链接除外。
- 即时卡片最多 900 张；打开过的最近 20 张保存到 sessionStorage。国家范围搜索不擅自给结果分配城市。

底图为 OpenStreetMap 标准瓦片，保留署名；不预抓取。底图失败仍可显示本地国界与卡片坐标。坐标为位置参考，不保证入口、营业、菜单或库存；OSM 可能过时或缺失。

## 内容与文件

- `data.js` / `app.js` / `style.css`：87 个四语词条、词源、图示、搜索、收藏与朗读。图片为辅助图示；词源未收录会说明并提供 Wiktionary 入口。
- `guide-data.js` / `guide.js` / `guide.css`：三国十城资料与共用页面。城市含河流、季节气候、货币与相对物价，气候不是实时预报、物价不是实时报价。
- `card-graph.js`：卡片注册、明确的双向关联、详情、来源与即时卡片恢复。
- `knowledge-hub.js` / `.css`：范围、一级/二级分类及说明、筛选、可达性清理与地图行为的统一入口。
- `poi-data.js`：60 条城市美食介绍（含跨城常见食物）、46 个交通与商业地点。
- `country-knowledge.js` / `travel-tips.js`：国家趣闻、特产与容易忽略的小事。
- `travel-tickets.js`：十城买票说明和 Deutschlandticket，比较单次/多日/周/月票、机场区域、验证与续订；通过官方入口核对当前票种和价格。
- `brand-data.js` / `people-data.js`：企业、国民零食饮料、人物与明确的场所关联。
- `discovery-data.js`：餐饮、文化场馆、轮渡与交通工具；连锁品牌和示例门店分别建卡。
- `floating-map.js` / `.css`、`poi.js` / `.css`：随身地图、完整地图与动态门店。
- `borders.js`：Natural Earth 110m 国界，公有领域。
- `vendor/leaflet`、`vendor/markercluster`：Leaflet 1.9.4（BSD-2-Clause）、MarkerCluster 1.5.3（MIT），许可证随文件保存。

品牌起源、当前所有权、经营市场、总部与公开参观场所分开描述。药妆店不等于配处方药的药房。美食详情保留口味比较、保存与购买说明、Commons 图片搜索链接；关联餐馆不保证供应某道菜。官方链接包含专题、首页和查询入口，未逐项实网核验。

使用已安装的 Playwright 和 Chromium，启动本地服务后：

```sh
SITE_URL=http://127.0.0.1:3014 node tests/map-tree.cjs
SITE_URL=http://127.0.0.1:3014 node tests/card-contract.cjs
SITE_URL=http://127.0.0.1:3014 node tests/guide.cjs
SITE_URL=http://127.0.0.1:3014 node tests/card-paths.cjs
SITE_URL=http://127.0.0.1:3014 node tests/series-layers.cjs
SITE_URL=http://127.0.0.1:3014 node tests/card-map-source.cjs
SITE_URL=http://127.0.0.1:3014 node tests/search-and-tickets.cjs
SITE_URL=http://127.0.0.1:3014 node tests/brands.cjs
SITE_URL=http://127.0.0.1:3014 node tests/city-details.cjs
SITE_URL=http://127.0.0.1:3014 node tests/travel-tips.cjs
```

`map-tree.cjs` 检查三层来源、单卡开关、父级半选与批量选择、折叠不改变勾选、键盘、逐卡偏好、旧偏好迁移、城市隔离、动态查询和结果数量、地图与树互相定位，以及国家/手机布局。

`card-contract.cjs` 从实际页面展开与分页收集全部卡片，检查保留的详情均可达、单 POI 约束、分类说明、无坐标卡片不继承地点、国家/城市地图入口、共享品牌语境与旧详情清理。其他回归覆盖十城筛选、知识跳转、词典、移动端、来源一致性、动态品牌限制、聚合、缓存、取消与超时。

测试主动阻断瓦片并使用受控 Overpass 响应。当前云代理对 Overpass 的请求返回 403，因此模拟通过不表示公共地点接口实网已连通；用户网站请求来自访问者浏览器。TLS 校验保持开启。
