# 漫游词典 · Eurotrip

面向匈牙利、奥地利和德国旅行的中文词汇学习网站。词条按中文、英语、匈牙利语、德语排列，覆盖八个生活场景，支持跨语言搜索、浏览器本地收藏、设备语音朗读和词条详情。

## 本地运行

无需安装依赖，使用 Python 3：

```sh
cd /workspace/eurotrip
python3 -m http.server 3000 --bind 0.0.0.0
```

打开网站即可使用。主词库与彩色图示保存在本地；外部字体不可用时自动使用系统字体。词典链接需要联网。语音支持取决于设备及浏览器的语言包，收藏保存在当前浏览器。

## 文件

- `index.html`：页面和详情对话框
- `style.css`：桌面与手机布局
- `data.js`：多语言词库及已收录的词源说明
- `app.js`：分类、搜索、收藏和朗读

词源未收录的词条明确标注，并提供 Wiktionary 查阅入口。图像是辅助记忆图示而非实物照片。尚未接入真人录音或后台账户。

## 分层城市探索与即时 POI

城市介绍新增四个栏目：当地美食、超市品牌、机场/火车站、热门商圈。`poi-data.js` 收录 10 城的美食概览与 46 个精选交通/商业地点；`poi.js` 实现父图层、子图层独立开关，以及按城市保存在浏览器中的显示偏好。食品简介不表示附近每一家餐馆都供应这些菜。

实时地点来自 OpenStreetMap Overpass，浏览器直接 POST 至 `https://overpass-api.de/api/interpreter`，无需密钥。节点和面状地点（center）均可显示。超市别名归并如 INTERSPAR→SPAR、ALDI Süd/Nord→ALDI；奥地利 HOFER 单列。品牌清单为分类，不能据此断言某城有该品牌门店。

为控制全城门店数量和公共接口负荷：

- 默认只显示精选景点；勾选栏目后查询当前视野，或点击“搜索当前地图范围”。
- 查询必须 zoom≥13，视野宽、高各不超过15km；移动地图默认不联网，用户可启用900ms防抖的自动搜索。
- 查询输出最多201条以判断截断，实际保留最多200条；达到上限明确提示结果不完整，建议缩小范围。
- 查询范围/类别完全相同时使用10分钟内存缓存，最多24组；图层开关650ms防抖、只保留一个活动请求，切城市销毁并取消请求。
- 使用本地 Leaflet.MarkerCluster 1.5.3（MIT）聚合；最多显示离地图中心最近的30个列表条目，地图仍显示全部已载入且启用的地点。最大缩放下可展开重叠点。
- 请求失败、限流、超时/Overpass remark 不视为“没有门店”；保留已有数据并明确标识范围尚未更新，提供外部地图搜索入口。空成功结果也不保证现实中没有地点。

瓦片和Overpass接口需联网与跨域支持。当前云代理尚未放行新的服务域名，实网查询暂未验证；域名及更新后的启动说明已存环境草稿。公共网站的请求来自访问者浏览器，不依赖云容器代理。OSM数据可能缺少名称/地址、过时或不完整；营业时间标签不等于实时营业状态。

`node tests/card-map-source.cjs` 使用受控的Overpass响应检验品牌筛选、不同栏目共存、点聚合、范围保护、缓存、服务器限流/超时、200条截断、POI弹窗、手机布局及切城隔离。模拟测试不代表真实Overpass服务已连通。

## 景点分类、城市环境与美食比较

现有 10 城共 50 个精选景点，按教堂、博物馆/美术馆/展览、大学、地标建筑、公园/其他分类。城市页支持各类别独立控制地图与卡片显示，筛选偏好按城市保存。大学坐标代表标注的主楼或校区区域，不代表大学所有设施；综合建筑群使用一个主要分类。

每个城市新增河流与地形、概括性季节气候、货币、相对物价描述。气候不是即时预报，价格不是实时报价，不能用作固定预算或天气保证。

每城提供 6 条美食介绍，共 60 条城市美食记录（含跨城常见食品，非 60 种独有美食），可在统一知识库的“美食与特产”中按类型过滤，查看口味/做法/同类食物比较。图片链接是 Wikimedia Commons 的图片搜索入口，不是指定餐馆照片；未逐项验证外部图片搜索结果。饮食限制须与店员确认。`node tests/city-details.cjs` 验证分类同步、偏好保存、河流/货币、价格提示、美食筛选和图片链接结构。

## 完整城市地图：以卡片为唯一内容来源

`CityExplorer.mount` 现在直接遍历 `KnowledgeHub.scoped` 与 `mappedPoints`，从卡片注册表生成五个系列图层、细分类别和地点。地点名称、描述、编号、归属与详情链接均读取同一张地点卡片，不再读取 `poiCityInfo.pois` 或单独注入场所列表；旧的 `city.places` 标记也不再并行绘制。完整地图侧栏仅显示卡片地点，卡片没有明确坐标时不会任意补点。新增带坐标的城市卡片无需维护另一份地图数据。

默认不请求外部地点。可另外开启超市/连锁餐饮动态门店，仅允许当前国家已收录的超市品牌卡片或连锁门店示例中的品牌。搜索请求含品牌、名称或运营方匹配约束，响应再次核对品牌；不搜索普通餐馆、商场或交通枢纽。动态结果先登记为即时卡片，标注动态门店并双向连接来源连锁卡片，城市位置、编号及分类继续来自卡片。连锁门店示例来源不意味着搜索结果与示例是同一门店。

动态搜索类型启用后，移动地图默认经900毫秒延迟更新，可取消自动搜索。限制缩放≥13、范围每边≤15km、最多200载入结果、最近30条列表、10分钟/24项缓存，并保留取消、过期响应拦截、聚合和错误时保留结果。品牌与系列开关独立；每城保存卡片系列/细分/品牌选择，动态请求类型每次进入默认关闭。

`tests/card-map-source.cjs`替代原独立地点分类测试，验证地点文字和分类来自卡片、新卡片自动进入地图、默认零网络请求、按来源品牌限定搜索、无关餐馆/车站/门店不混入、移动搜索/缓存、动态品牌关联、200/30上限、范围限制、失败保留、手机和详情定位。即时接口使用受控测试响应，不表示Overpass实网已连通。

完整地图的图层面板现在直接列出各系列已收录的地点名称和编号，点击名称定位，旁边可打开来源卡片。名称列表可独立滚动。动态超市/连锁餐饮的开关与品牌列表并入购物/美食系列，每个品牌注明「动态搜索」，不再单列动态门店小框；既有搜索范围、缓存、自动移动刷新及失败保留规则继续生效。

电脑端随身地图默认面板宽460px、地图高340px（此前350px/240px），仍可继续放大；面板高度受视口限制，手机端保留底部面板尺寸。卡片按细类分组，并保留关键词/类别筛选、独立分页与地图反向定位；反向定位会展开对应细类并显示目标卡片。

国家选择统一收进顶部「国家知识」菜单。点击先选择匈牙利/奥地利/德国，再进入国家页；页面内不再重复显示宣传大标题和三国选择卡片，城市/地图/详情也可从同一菜单切换国家。菜单支持键盘方向键、Home/End、Escape、外部点击/焦点关闭，并标出当前国家；既有国家与城市直达链接继续有效。

## 搜索延迟、交通买票与分类图标

连锁门店查询将品牌/name/operator三次扫描合并为一次标签键正则扫描，每种门店类型一条空间查询；品牌别名去重，结果上限降为200（列表仍30）。范围按0.005度外扩对齐，减少小幅移动造成的查询差异；相同在途查询不重启，10分钟缓存可跨当前会话的页面刷新复用（最多8项持久化，内存24项）。服务端计算超时8秒，客户端等待上限10秒，显示已用时间并可取消。失败后自动查询冷却15秒，用户仍可手动重试，已有地点保留。

该云环境对overpass-api.de的实际请求被代理以403拒绝，因此不能据此判断用户浏览器访问公共Overpass的真实排队/网络耗时，也未宣称固定提速比例。`tests/search-and-tickets.cjs`用受控延迟验证同范围请求去重、立即取消、缓存跨刷新、10秒结束等待、失败后冷却及保留旧结果。其他地图与品牌回归测试继续使用受控服务响应。

`travel-tickets.js`新增十城交通买票卡片和德国Deutschlandticket说明，归入必备信息（卡片一级分类）下的交通买票（卡片二级分类）。比较单次/日票/多日、周/月、实名、验证、机场区段、续订及日历月等差异；不固定承诺票价、停售/在售产品或取消截止日，提供运营商票务入口核对。

`KnowledgeHub.iconForSub/iconForNode`集中维护卡片二级分类图标；一级分类使用🧭🍽️🛍️💡🏛️。分类标题、标签、详情、小地图图例及两种地图大头针共用图标，地点编号继续保留。例如🎫票务、✈️机场、🚉火车站、🛒超市、☕咖啡、⛪教堂、🏛️博物馆、🎭剧院。图标使用系统Emoji，无外部图标请求。
