# 县镇风味：本轮条目核对

新增14项：浙江13项、河南禹州1项；总目录1321项，至少2000项的目标尚差679项。按已有八个品类收录，具体县镇以 `locality` 显示和搜索，不将地级市市区等同于全市覆盖。县级检索目录与食品来源证据分开记录。

## 采用

- 临海蛋清羊尾：蛋清打成泡沫包豆沙炸制，名称取形，不是羊肉。采用具体做法报道，未写“国宴级”，未在没有名录原件时写确定非遗级别。
- 兰溪鸡子馃：鸡子馃／鸡子粿合并。百科正文说明肉葱油煎饼灌蛋，文旅活动及游埠早茶报道支撑地域与消费关联；不照录未找到原始名单的“2024十大”等荣誉。
- 梁弄大糕：县镇归余姚梁弄；采用米食、糕面印字、婚亲与节令分享等可核对事实。未把不同来源的创始年、年数和非遗级别混为结论。
- 衢州烤饼：新增独立面食，口头烧饼叫法可搜索。与邵永丰麻饼、衢州酥饼等不混同，未以不同大小或馅口拆成重复卡。
- 兰溪手擀面、咸汤圆、烧麦、清明粿：报道提供具体面料、馅料、造型与加工线索，按原料和工艺重新编写。来源含商业推广性质，未采用销量、排名、速食复刻保证。
- 龙游北乡汤团、粉干、米糊、豆腐丸子：同一专题的具体工艺与原料段落分别支撑。汤团／汤圆合并，豆腐丸子归菜，米制主食归面食。
- 苍南海蜈蚣：只按海产食材收录，以苍南食品报道和沙蚕百科交叉确认地域及动物类别；未据“采捕基地”字样直接添加菜式，也未照写药效。
- 禹州杂炣（zá kě）：与用户“杂珂”的读音线索对应。新闻正文明确禹州杂炣，百科正文明确禹州顺店镇、牛杂、禹州粉条与炸豆腐条。按许昌—禹州—顺店镇归属，不因报道中的展销地点在郑州而归入郑州。排除百科中帝王传说和通用牛杂火锅等混入内容。
