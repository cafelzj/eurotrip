## 研究与编辑

检索覆盖各省市食品类别，随后直接查阅文旅资料、地方饮食文献、品牌官网、公开公司资料与百科条目。Bing 搜索曾返回与查询不相关的结果；Google、搜狗和部分百科页面出现验证码；部分官网拒绝连接或只有未能加载的壳页面。这些结果不当作有效证据，也不绕过验证码。

实际采用的资料包括北京旅游网、品牌官网、公开公司资料；中国新闻网、中国日报网地方版的具体市县食品报道；《中华遗产》地方食品与调味文化文章；已读取的茶叶与地方乳业百科、菜系综述及 TravelChinaGuide 的具体做法介绍。公司资料只采用品牌、地址、业务类型和有关历史，不引入投资信息或经营宣传口号。企业自述的获奖、远古起源、销量排名和保健功效没有作为收录结论。

- 每条正文为编辑整理，保留所参考资料的原始标题、出版方、链接和核对日期，不整页转载。
- 分别记录地方品牌、茶庄零售地和原料产地；北京花茶、上海茶庄等不被写为当地种茶。
- 含乳饮料、植物蛋白饮料与乳制品分列。山西药茶以代用茶品类记录；没有附加医疗效果。
- 列入奶茶系列的地方饮品不自动被写成连锁品牌；香飘飘标为冲泡产品，茶饮店标为现制。品牌在外地开店与本地起源是两类事实。
- 先能核实品牌身份的条目明确说明还待补具体单品。上海老字号名录通过已读取的维基页面中的展开名录核对；审阅记录提供 `readVia`。
- 山东高汤按烹调底汤收录，明确奶汤的汤色含义；不作乳饮料或包装商品介绍。
- 来源成功返回 200 仍可能是错误页、同名楼盘、域名出售页或百科首页；这些页面均没有列作通过。来源审阅记录只给实际采用的材料标记 `read: true`，附读取内容的 SHA-256。
- 新栏目未生成食物图片，也没有用不相关照片、AI 景点插画或空白图片框补位。原有食物图片、来源和拒绝清单均保留。

## 地图

全国轮廓来自 [阿里云 DataV 地理小工具](https://datav.aliyun.com/portal/school/atlas/area_selector) 公开的 [100000_full.json](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)，下载于 2026-11-14。保留原始 34 个省级区域及海域界线，投影为本地 SVG，并提供南海诸岛附图；七个已选录区域可点击，也提供独立省市按钮与键盘入口。

全国图与所选省市图同时展示：桌面左右排列，手机上下排列。七份省市边界使用同一来源的 `110000_full.json`、`370000_full.json`、`340000_full.json`、`320000_full.json`、`330000_full.json`、`310000_full.json`、`140000_full.json`，合计 **67 个地级市、32 个直辖市辖区**。北京、上海中心城区使用引线标注，避免文字重叠。

点击城市或区可筛选，支持键盘，选择写入网址，刷新、前进后退仍可恢复。区域数字随类别、搜索和食材条件变化；没有具体归区的全市食品单独提示数量，不随意放到某个区。地图中零条目的地区仍可选择并保留筛选状态。全国图、省图任一加载失败时，另一幅图和下拉选择仍可用。

地图旁保留来源链接。DataV 地理数据未被擅自标为 Wikimedia、CC 或 Apache 许可；与本项目自行编写的 SVG 生成代码分别处理。只作目录中的分省浏览，无在线底图、瓦片、定位或外部地图接口依赖。地图文件加载失败时仍可使用省市按钮。

复现生成：

```sh
python3 scripts/build-china-province-map.py /path/to/100000_full.json
python3 scripts/build-flavor-province-maps.py /path/to/seven-province-json-directory
```

第二个目录中的输入文件按行政区代码命名，例如 `110000.json`。工具同时生成本地省市 SVG 和 `data/flavor-map-regions.js`；来源、边界数量及原始文件和 SVG 的 SHA-256 记录在审阅清单的 `provinceMaps`。

## 维护和验证

- `data/flavors.js`：省市、七类食品、食材标签、来源和条目。它与 `CardStore` 旅行卡片数据分开，避免污染原有地点、图层和卡片分类约束。
- `flavors.js`、`flavors.css`：渲染、筛选、来源展开与本地地图加载。省市、城市、类别、搜索和食材筛选写入地址，支持分享、刷新与前进后退。
- `assets/maps/china-provinces.svg`、`assets/maps/flavors/`：按需加载的全国与七省市地图；`scripts/build-china-province-map.py`、`scripts/build-flavor-province-maps.py` 为生成工具。
- `tests/flavors.cjs`：来源与城市归属、99 个市区边界、双图共存、地图与文字入口、城市/区/类别/食材/搜索、奶茶分类、网址恢复、零结果状态、两种独立加载失败、五种宽度及无外部数据请求。

浏览器验证不证明所有地方做法已穷尽，也不把百科和企业叙述等同于已经交叉考证的历史定论。扩充时继续逐条核对来源，尤其是具体市县归属、品牌归属和地方食品的不同做法。
