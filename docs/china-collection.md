# 中国城市与风物统一卡片

更新：2026-11-15。新版入口为 `#card-manager/china`。同一批卡片可切换瀑布流、分类浏览和表格；一级、二级分类均以带数量的可点击分类卡片呈现。

## 一套数据，中国总览统一浏览

运行时统一以 `CardStore.nodes` 为正式卡片注册库。原风物食单4255项已全部纳入中国栏目，独立入口已撤下，旧链接转入总览。`data/flavors.js`、既有城市卡片和阅读配置作为编辑输入，原始ID、研究稿、旧文字和证据继续保留，不把整份风物内容再复制成一套B页面数据。

4255项风物全部注册为中国卡片。原有142张中国卡片中，12张与风物指向相同食物，合并后共有**4385张中国卡片**。例如苏式汤面、松鼠鳜鱼、响油鳝糊、碧螺春、无锡小笼包、奥灶面等只保留一个规范身份；旧ID仍能访问，关系、来源、旧文字和图片引用一并保留。食品概览和具体品种、店铺不无条件合并。

采用关系和原始数据来源见 [统一登记](../research/flavors/integration/china-collection.json)。所有历史底稿统一从 [风物研究总入口](../research/flavors/README.md) 查找。

## 独立分类

中国分类配置在 `data/china-categories.js`，欧洲配置继续在 `data/categories.js`；共用组件与CSS，分类定义独立。中国“美食与特产”的二级分类包括：乳制品、饮品、酒、茶、特色菜、面食、地方食材、调味品、物品与工艺；餐馆和食品品牌合并为“餐馆与食品品牌”，连锁餐饮归同类；点餐提醒归“日常／应急”。交通与方言分类同步精简，详见 [迁移与保留说明](flavor-migration.md)。

## 地区与资料边界

地区目录覆盖既有风物范围的15省市、174个城市筛选范围和1484个县级单位。`data/china-region-catalog.js` 采用行政代码关联，原有苏州、无锡、徐州及11个县级目的地ID不变。直辖市和省直管县级城市按实际层级处理。

中国总览复用原风物食单的省市县清单及本地地图组件，数字随分类、搜索和资料状态变化。未明确县区的1269项风物保持待定位，不复制到所有县。47项待核实线索继续标识和筛选；已有链接也不等于全部事实已经验证。

行政中心坐标只用于地区地图视角，**不作为地方食品的店铺或POI**。全部4255项风物不因导入而产生虚构地点；原有城市场所的真实定位及动态搜索功能继续保留。

## 浏览与兼容

- 瀑布流每批24张，逐步加载；展开说明、图片载入与字体变化会重新测量卡片高度，切换页面后清理观察器。
- 分类浏览按一级、二级类别分组，支持收起和继续加载；风物正文及原城市卡片补充内容在卡片内阅读。
- 表格支持每页25／50／100张、翻页和CSV导出；风物名称及“展开说明”按钮均原位展开正文，不跳转独立说明页。导出全部筛选结果，保留来源、地域、待核信息和旧ID。
- URL保存地区、类别、关键词、资料状态、视图及分页；欧洲和中国的已保存筛选独立。旧中国管理页的城市ID参数会转换为省市县条件。
- 搜索包含规范名称、旧卡片名称、说明、来源与地区。照片沿用已审核真实图片，未配图状态不因合并而改变。

## 验证

`tests/china-collection.cjs` 覆盖4385张统一卡片、4255项完整性、12个旧ID、独立分类、三级地域、三种视图、CSV、URL恢复、五种宽度、瀑布流展开和地图失败回退。`tests/card-manager-regions.cjs` 验证欧洲和中国的筛选与来源隔离；其余沿用风物、图片、地图与欧洲卡片回归检查。技术测试不代替食品事实验证。

导航采用省 → 市 → 县区逐级菜单；“总览”始终置于第一项，支持返回上一级、全省及全市总览、方向键与Esc。

界面采用城市卡片共用的紧凑筛选按钮，图标、分类名称和数量同排。省、市、县区清单按钮按内容宽度换行；城市清单与地图在前，县区清单与地图在后，上下排列，未选城市时收起空县区提示。城市页直接从单行省市县下拉框进入卡片，移除重复面包屑、装饰横幅和通用说明，保留可访问的页面标题。
