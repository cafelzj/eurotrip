## 画风选择

优先使用当地景观、艺术传统和时代语境，再选择现代插画语言。选择规则是编辑判断，不声称某位艺术家画过该地点，也不把新作冒充历史作品。战争遗址和纪念场所采用克制的灰阶素描，不作娱乐化演绎。

- 匈牙利：多瑙河水彩、中欧新艺术海报、风景油画与建筑版画。
- 奥地利：维也纳分离派装饰、建筑水彩、奥地利风景油画；莫扎特故居结合古典音乐线索。
- 德国：包豪斯几何、表现主义木刻、建筑钢笔淡彩和当代水粉。
- 塞尔维亚：多瑙河风景油画、巴尔干装饰版画；特斯拉题材结合蓝晒和电气时代图形。
- 斯洛文尼亚：山水水彩、步行尺度建筑线描、亚得里亚海水粉。
- 波兰：旅行海报、装饰艺术、剪纸版画；肖邦题材结合浪漫主义音乐。
- 中国城市：江南水墨、吴门山水意境、青绿山水、木刻与现代水粉；汉文化结合汉俑和画像石题材。

## 配置与呈现

`data/landmark-art.js` 是纯 JSON 形式的常量，使用稳定卡片 ID 索引；每条记录包含本地大图、缩略图、尺寸、画风、画风由来、替代文本、AI 属性与日期。只有明确配置且属于景点一级分类的卡片展示图片。地图、归属、搜索及关联逻辑保持独立。

`card-art.js` / `card-art.css` 供分类列表、瀑布流与详情复用。列表图片延迟加载，详情立即加载。首批独立图片提供 480px / 1200px WebP；批量图片使用 2×2 图集，每个象限是独立的景点画面，提供 960px 缩略图与原尺寸 WebP。浏览器只显示当前卡片对应的一个象限，不把整张拼图放上卡面。同一图集可被浏览器缓存复用，减少邻近卡片的重复下载。

图片容器始终预留 3:2 比例，`srcset` / `sizes` 考虑图集的显示尺寸。图集详情的显示宽度不超过单幅画面原始宽度。图片无法加载时，在同一尺寸内显示简短占位，不影响正文、详情入口或地图按钮。

卡面标注画风和「AI 艺术插画」，详情补充「非实景照片」与画风由来。其他分类没有图片时不显示空白图框，不自动从网络抓取照片，也不在访客浏览时调用模型。

## 增补与检查

先确认具体题材与卡片对象一致，再通过图像生成工具创作；避免给泛城市卡片套用另一处景点的画作。导出网页版本只进行等比缩放、格式转换和压缩，不更改画面内容。原生成文件保留在生成目录，仓库只存部署所需资产。以后加入真实照片，应另外记录原始页面、作者和许可，不能沿用 AI 插画的标记。

`docs/landmark-art-prompts.json` 保存本轮逐场所的题材、风格选择理由、完整创作提示和象限分配。每组生成后保存一份本地记录，例如 `{"id":"atlas-hu-01","source":"/workspace/generated_images/example.png"}`。使用 ImageMagick 7 导出网页资源并生成配置：

```bash
python scripts/build-landmark-art.py --sources /tmp/eurotrip-art-batch
```

脚本不代替图像模型创作，也不裁改画面内容。`--partial` 仅用于本地分批预览；默认要求全部生成记录就绪，避免发布时把未完成的配图当作完成。原生成目录与本地记录不随网站部署。

新增资产后，运行：

```bash
SITE_URL=http://127.0.0.1:3026 node tests/landmark-art.cjs
```

测试要求所有静态景点卡片都有对应图片，核对象限、同地共享、文件格式、实际尺寸、体积和风格说明，并检查列表 / 详情、响应式瀑布流和失效占位。同时人工查看题材与手机 / 电脑裁切。
