## 配置与呈现

`data/landmark-art.js` 是纯 JSON 形式的常量，使用稳定卡片 ID 索引；每条记录包含本地大图、缩略图、尺寸、画风、替代文本、AI 属性、创作说明与日期。只有明确配置且属于景点一级分类的卡片展示图片。地图、归属、搜索及关联逻辑保持独立。

`card-art.js` / `card-art.css` 供分类列表、瀑布流与详情复用。列表图片延迟加载，详情立即加载。480px 与 1200px 两档 WebP 使用 `srcset` 和 `sizes`，图片与容器均预留 3:2 比例，避免加载前后改变卡片高度。图片无法加载时，在同一尺寸内显示简短占位，不影响正文、详情入口或地图按钮。

卡面标注画风和「AI 艺术插画」，详情补充「非实景照片」。未配图的卡片不显示空白图框，不自动从网络抓取照片，也不在访客浏览时调用模型。

## 增补与检查

先确认具体题材与卡片对象一致，再通过图像生成工具创作；避免给泛城市卡片套用另一处景点的画作。导出网页版本只进行等比缩放、格式转换和压缩，不更改画面内容。原生成文件保留在生成目录，仓库只存部署所需资产。以后加入真实照片，应另外记录原始页面、作者和许可，不能沿用 AI 插画的标记。

新增资产后，在配置中填写其尺寸、明确替代文本与画风，并运行：

```bash
SITE_URL=http://127.0.0.1:3026 node tests/landmark-art.cjs
```

测试核对图片与现有卡片、文件格式和体积，检查列表 / 详情、响应式瀑布流和失效占位；同时人工查看题材与手机 / 电脑裁切。
