# 新版与原版切换

2026-11-13：在已发布版本 `ee86be8` 的基础上增加可切换的紧凑优化版本。两种版本共用内容、图片、许可、地图与路由，不复制卡片数据。原版保留原来的大封面、长介绍、图片框、配色和卡片布局；顶部新增的样式切换入口为两个版本共用。

顶部「新版／原版」可随时切换。默认新版，选择保存在当前浏览器的 `roam-notes-style` 中；浏览器禁止存储时，当前页面仍可切换。URL 的 `?style=new`、`?style=classic` 可用于分享和直接对比，优先于浏览器偏好；从这类链接切换时同步更新参数。切换不刷新文档，不清空城市、分类、搜索、浏览模式或已选相册照片。

新版的第一轮改动：

- 进入美食、交通等具体分类或搜索时，默认收起目的地大图与介绍，保留城市标题和切换按钮；点击「展开介绍」恢复封面、完整介绍与官方旅行指南。国家概览仍展示完整封面。
- 手机导航保留欧洲国家、中国城市和旅行词典，物产与方案收进「更多」；原版与桌面版仍显示原有入口。菜单保持同一批按钮和事件，支持键盘与 Escape，切换版本和屏幕宽度可恢复原位置；手机国家与中国城市菜单保持在视口内。
- 图框按每组相册的真实尺寸确定比例，横向包装减少上下空白，纵向图在详情中按实际比例居中完整呈现。每组相册切换时保持框高，逐图说明、作者、来源与许可不变。列表菜品保留裁切预览，详情完整显示；人物仍保留专用框形。
- 新版列表和详情导语使用各卡片原始目录中的短介绍；完整历史文字、来源与关联保留在详情正文。原版继续显示原有的长介绍。统计数据的年份、币种与人均／每户等口径不改写。
- 加深外文副标题与辅助文字，放大有关标签，简化详情中与标题完全重复的外文行。
- 有相关资料的目的地显示「物价与开销」快捷入口，直接使用现有分类与数据；没有相关卡片时不展示这个入口。

本轮 390×844 手机布局量测：美食列表第一张卡片约从原版的 Y=947 提前到新版的 Y=524；Prince Polo 横向包装的详情图框由 243px 减为 108px，保留完整图片和相册切换时的固定高度。

实现位置：`site-style.js` 在样式加载前确定版本，监听切换并同步导航与偏好；`site-style.css` 将新版覆盖规则限定在 `html[data-site-style="new"]` 内。`card-summary.js` 根据 `CardStore` 保留的原始短介绍渲染两种文案，完整编辑内容不变。`card-images.js` 为每组相册提供固定比例变量。

`card-feed.js` 在切换版本时重新测量卡片；测量期间保留网格的高度，避免临时清除卡片坐标时页面变矮、把滚动位置归零。初次挂载也先确定实际高度，再由路由恢复阅读位置。没有改写同国内城市切换的路由实现。
