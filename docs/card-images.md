# 人物与美食配图

2026-11-07 首批为 191 张卡片匹配 163 个 Wikimedia Commons 文件：58 张人物卡、133 张美食、饮品及零售商品卡。同菜式的重复卡片复用同一文件。其余 41 张保留文字，等找到对象和许可都明确的素材再补充。

素材在 `data/card-images.js` 独立维护：每个文件记录缩略图地址、尺寸、中文替代文本、图注、作者或指定署名、许可及许可链接、原始文件页和核对日期。`cards` 只将已有卡片 ID 映射到素材，不改变卡片归属、知识关联或地图行为。

美食采用实拍，不生成照片。选图核对 Commons 文件说明及许可，修正了百科首页图的错误跳转和不匹配结果，例如烙馍 → Luomo 音乐人、卷心菜 Sarma → 葡萄叶卷、品牌商品 → 工厂或标志、Tokaji Aszú → Szamorodni、奥地利培根 → 意大利南蒂罗尔产品。Pick、Pöttyös、Univer 使用可确认品牌的实物图；糕团、混合食品和包装版本在必要时注明所示的一例。历史人物使用照片、绘画或雕塑；莫扎特、刘邦等后世画像在图注说明。

`card-images.js` 共用于分类列表、瀑布流和详情。列表按需加载，详情立即加载；人物和包装保留完整画面，菜品列表提供裁切预览，详情完整显示。图片区域预留比例和尺寸，加载失败后在原位置显示提示，正文和详情入口继续可用。详情保留作者、Wikimedia Commons 原始文件页及许可入口；图片继续适用各自许可。

当前图片由访问者浏览器直接请求 Wikimedia 缩略图，没有运行时搜索或随机图库。远程服务的可用性影响图片显示；云端执行环境的域名白名单不包含 Wikimedia，因此本地无法直接下载照片或验证浏览器到图片 CDN 的完整链路。资料查询通过可用的网页工具完成。自动测试以受控图片响应检查布局、加载成功与失败、署名、键盘跳转和响应式，不把该结果当作真实照片内容或 CDN 连通性的验证。

验证：`node tests/data-integrity.cjs`，`node tests/card-images.cjs`，`node tests/card-feed.cjs`。浏览器测试使用 `SITE_URL` 指定运行中的本地站点。
